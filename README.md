# PERSONNEL TRACKING & SALARY MANAGEMENT SYSTEM

---

## About The Project
Personnel & Salary Management System is an application developed using Object-Oriented Programming (OOP) principles.  
The project aims to manage employee information, support different personnel types, and calculate salaries efficiently.

---

## Features
- Object-Oriented Programming (OOP)
- Use of Abstract Classes and Interfaces
- Full-time and Part-time employee support
- Add and list personnel
- Salary calculation
- Clean and modular code structure
